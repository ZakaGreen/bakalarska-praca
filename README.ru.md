# Бакалаврская работа — будущие события и доходность акций

**Ilia Liubotin · прикладная информатика · FEI STU, Братислава**

Тема исследования: **прогнозирование влияния публичных новостей и вероятных будущих событий на доходность акций с помощью языковых моделей**.

## Текущий статус

**Ранняя стадия исследования и подготовки.** Сейчас репозиторий содержит окружение для написания работы в LaTeX и материалы шаблона. Готовой работы, обученной модели прогнозирования и экспериментальных результатов пока нет. Файл `thesis.pdf` — рабочий документ на основе шаблона.

## Направление исследования

Я изучаю, как описывать событие, которое может произойти в будущем, и оценивать возможную реакцию фондового рынка, если оно произойдёт.

Планируемый подход разделяет два вопроса:

1. Насколько вероятно, что событие произойдёт?
2. Какая реакция может последовать, если оно произойдёт?

Исторические новости и рыночные данные предполагается использовать для обучения и оценки. Основной интерес — применить эти знания к **вероятным будущим событиям**, учитывая момент доступности информации и избегая утечки данных из будущего (look-ahead bias). Это исследовательские цели, а не уже реализованные возможности.

## Шаблон и сборка

Окружение для написания основано на [FEIStyle](https://github.com/Kyslik/FEIStyle). Исходная документация сохранена в [docs/FEIstyle-README.md](docs/FEIstyle-README.md), оригинальная [лицензия](LICENSE) также оставлена.

При установленной подходящей сборке LaTeX, `latexmk`, Biber и необходимых пакетах Makefile предоставляет команду:

```bash
make
```

Промежуточные файлы сохраняются в `.build/`, итоговый `thesis.pdf` — в корне репозитория. При обновлении документации портфолио сборка работы повторно не выполнялась.
