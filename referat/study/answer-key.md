# Ключ для самопроверки

Сначала отвечайте без подсказок. Ссылки ниже относятся к разделам нашего реферата; в них указаны локаторы первоисточников.

1. События из статей, связанных с акцией i за период t, и идентификатор акции; цель — фактическая доходность следующего дня/недели. §2.
2. LLM выдаёт структурированные события. Число доходности выдаёт отдельный обучаемый предиктор. §§3–4.
3. Subject, action, object, ссылки на субъект/объект, context. Предиктор получает обучаемые представления индексированных троек и акции; нельзя автоматически приписывать ему отдельный вход context. §3.
4. Унификация названий сущностей и близких действий, снижение повторов и разрозненности одних и тех же сигналов. BERT+DBSCAN для действий — этап предобработки, не весь предиктор. §3.
5. Fuzzy matching имени, не менее двух упоминаний, лучшее совпадение, исключение неоднозначных имён. Stock-ID — обучаемый вектор уже определённой целевой акции. §§2–3.
6. Вектор события размерности M. Авторы связывают его с TransE; отдельные margin loss, negative sampling и этап предобучения TransE в нашей работе не утверждаются. §3.
7. (N+2)×M: N событий, одна строка CLS и одна строка акции. §4.
8. Q и K дают совместимость входов; softmax нормирует веса по строке; они агрегируют V. Разные головы используют разные обучаемые проекции. §4.
9. CLS собирает фиксированное по размеру представление для регрессии; название токена не определяет тип целевой переменной. §4.
10. Сначала attention событий внутри дня, затем attention по дневным представлениям с Weekly-CLS. §4.
11. Embeddings, attention и MLP, не GPT-экстрактор. Скалярный результат может иметь знак, но не обучается как калиброванная вероятность положительного дохода. §4.
12. Базово пять лет обучения, следующий год теста, поздние окна расширяются. Пять-fold CV в первом train-окне каждой группы из пяти моделей; параметры затем переносятся. Хронологичность внутренних folds не описана. §5.
13. Годовой показатель long–short портфеля на дневных прогнозах и Sharpe ratio. Это не 10,93% за день, не точность направления и не ошибка индивидуального прогноза в процентах. §5.
14. Сигнал может исчезнуть при задержке, затраты меняют итог, поздняя LLM и внешние знания создают риск исторической утечки. Сам риск не доказывает недостоверность результатов. §5.
15. Будущие события и ранжирование отраслей. Обновляются текстовые стратегии с обратной связью, не веса LLM обычным backpropagation. §6.
16. После прогнозируемого периода, для обновления стратегии на дальнейшие прогнозы. §6.
17. Разные состояния информации и ожиданий; часть ожидаемой новости могла быть учтена в цене. Предиктор последующего дохода по опубликованной информации не становится автоматически моделью условного или причинного эффекта гипотетического исхода. §7. При этом опубликованные новости сами могут обсуждать ожидания: SER нельзя описывать как исключительно корпус уже реализованных событий.
18. Доступные к моменту решения описание, срок, вероятность, сведения об акции/рынке; целевой фактический доход после исполнимого входа. Нельзя брать обновлённую после исхода вероятность или заранее известную будущую котировку. §7.
19. Для двух исходов нужны p·E[r|A,I]+(1−p)·E[r|не-A,I]. Если модель уже оценивает E[r|I], повторное умножение необоснованно. Рыночная оценка вероятности может быть некалиброванной. §7.
20. Не подтверждены объединённый датасет, достаточность независимых примеров и успешность прототипа; не выбраны окончательно события, акции, источник и горизонт. ФРС только кандидат. Мультиагентность, RL, самостоятельная генерация сценариев и вероятностей не обязательны. §7.

## Практические задачи

**Вероятность:** 0,6×4% + 0,4×(−2%) = 1,6%. Использование только 0,6×4%=2,4% игнорирует второй исход. Повторное умножение 1,6% на 0,6 не следует из закона полного ожидания.

**Время:** для решения в 10:00 допустима вероятность, действительно доступная тогда, в примере 0,55. Значение 1,00 из 14:05 раскрывает будущий исход. Вход возможен не раньше доступности всех входов и завершения обработки/передачи заявки; нужна доступная для исполнения котировка с учётом рыночного режима. Без этих данных нельзя назвать точную цену. Издержки отдельно учитываются при оценке торгового результата.
